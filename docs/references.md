# References

**Provenance note.** This list was compiled from the author's knowledge without live database lookup during the build.
Titles, journals and years are believed correct, but volume and page numbers must be checked against the publisher or
INSPIRE/ADS before the list is cited in a paper. No reference has been invented; if an entry cannot be verified it should
be removed rather than corrected from memory.
